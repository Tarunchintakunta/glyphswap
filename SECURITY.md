# Security

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/Tarunchintakunta/glyphswap/security/advisories/new) for this repository.

Please include the version, the route, and a short way to reproduce the issue. Give the maintainers time to ship a fix before you publish the details.

Do not open a public issue for an unfixed vulnerability. Do not include live credentials in the report.
